# REAP Books — project site

The homepage, privacy policy and terms for [REAP Books](https://talktalkmake.github.io/reapbooks-site/),
local-first bookkeeping for small US agencies and independents.

Static HTML and one stylesheet. No build step, no dependencies, nothing fetched
at page load.

These three pages exist because Google requires a homepage, a privacy policy
and terms of service before an OAuth application can be published to
production — and REAP needs that in order to connect to a user's own Google
Sheets without their sign-in expiring every seven days.

The application source is at
[talktalkmake/reapbooks](https://github.com/talktalkmake/reapbooks), private
while REAP is pre-release.

Apache-2.0.
